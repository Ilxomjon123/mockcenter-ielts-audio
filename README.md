# mockcenter-ielts-audio

Listening audio for MockCenter IELTS practice tests, one file per part, e.g. `cambridge_20_1_1.mp3`
(book 20, test 1, part 1) and `cdi_vol1_test1_sec1.mp3`.

Served to the exam app via `https://raw.githubusercontent.com/Ilxomjon123/mockcenter-ielts-audio/main/<file>`.
Do not rename or move files: the MockCenter database stores these URLs.
